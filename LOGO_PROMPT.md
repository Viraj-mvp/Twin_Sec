# TwinSec Cyber-Physical Brand Emblem — AI Generation Prompts

This guide provides specialized prompts for **Gemini 1.5 Pro**, **Claude 3.5 Sonnet (Artifacts)**, **Midjourney v6**, and **DALL-E 3** to generate high-definition vector and raster brand assets for the TwinSec Cyber-Physical Platform.

---

## 1. Midjourney v6 / DALL-E 3 Prompt (High-Tech Vector Emblem)

```text
A striking neo-brutalist tech emblem for an industrial cyber-security digital twin platform named 'TwinSec'. Heavy 2D vector logo mark featuring two interlocking geometric shield octagons: the left shield in vibrant acid lime (#BFFF2E) representing digital cyber intelligence, and the right shield in warm bone cream (#F5F3E7) representing physical SCADA infrastructure. Thick solid black stroke outlines, sharp 45-degree angles, dark charcoal (#09090B) background, minimalistic reticle crosshair in the center with a glowing neon lime radar core dot. Clean, graphic design style, high contrast, flat color vector illustration, no 3D bevels, no gradient clutter, 8k resolution --ar 1:1 --style raw --v 6.0
```

## 2. Gemini 1.5 Pro / Imagen 3 Prompt (Industrial Cyber Badge)

```text
Create a high-impact vector logo mark for 'TwinSec', a cyber-physical SCADA digital twin simulation platform. The design must feature a bold octagonal security badge split diagonally. One half is styled in vivid acid-lime green (#BFFF2E) with circuit trace linework, while the other half is in technical paper-white (#F5F3E7) with industrial hazard hatch patterns. Encased in a thick 4px pitch-black border frame with a central glowing reticle node. Vector SVG style, sharp edges, extreme high contrast, clean cyberpunk brutalist aesthetic, isolated on dark charcoal backdrop.
```

## 3. Claude 3.5 Sonnet (SVG Vector Generation Code Prompt)

```text
Generate a clean, self-contained SVG icon component for a cyber-security platform named TwinSec. Requirements:
1. 100x100 viewBox, responsive, scalable.
2. Dual interlocking diamond/octagon shields: Acid Lime (#BFFF2E) and Technical Bone (#F5F3E7).
3. Heavy 3px solid black outlines with crisp 45-degree angles.
4. Animated or static central radar reticle with a glowing core signal dot.
5. High contrast, neo-brutalist industrial aesthetic. Output only valid SVG code inside a clean JSX wrapper.
```
